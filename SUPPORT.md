# Support

Machine Studio is a technical-alpha open-source project maintained on a best-
effort basis.

- Use a bug-report issue for reproducible defects in a supported workflow.
- Use a feature-request issue for scoped, vendor-neutral proposals.
- Use [SECURITY.md](SECURITY.md) for vulnerabilities; never report them in a
  public issue.
- Include the application version, full source identity when available,
  Windows version, reproduction steps, expected result, and actual result.

The project does not provide production equipment support, safety certification,
PLC/robot/MES/cloud integration support, vendor SDK support, or guaranteed
response times.
